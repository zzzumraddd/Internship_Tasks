
# Networking 1-lesson




# 1-task

Record all your home devices’ IPs and MACs using arp -a.

![App Screenshot](images/task1-1.png)

My home network has two entries in the ARP table. The first device is rtk_gw.bbrouter with IP address 192.168.1.1 and MAC address 60:d2:dd:50:76:76 connected via the en0 interface, which is my router. The second entry is mdns.mcast.net with IP address 224.0.0.251 and MAC address 1:0:5e:0:0:fb on the en0 interface, which is a permanent multicast address for mDNS service discovery.
